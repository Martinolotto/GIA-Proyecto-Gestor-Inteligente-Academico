# GIA - Gestor Inteligente Académico 🎓

Bienvenidos al repositorio de GIA, una plataforma diseñada para guiar a los estudia el ntes enpaso al nivel terciario y universitario, permitiendo la búsqueda y registro de instituciones. Además de guías generales para ayudar a los alumnos/aspirantes a poder guiarlos a esta nueva etapa.

## 🛠️ Estructura del Proyecto
El proyecto está dividido en dos capas principales:
* `/frontend`: Contiene las vistas estáticas (HTML), estilos (CSS) y la lógica de interacción del cliente (JS).
* `/backend`: Contiene el servidor en Node.js, las rutas de Express y el sistema de almacenamiento de datos en nuestra base de datos manejada con sequelize.
