# GIA - Gestor Inteligente Académico 🎓

Bienvenidos al repositorio de GIA, una plataforma diseñada para guiar a los estudiantes en el paso al nivel terciario y universitario, permitiendo la búsqueda y registro de instituciones. Además de guías generales para ayudar a los alumnos/aspirantes a poder guiarlos a esta nueva etapa.

## 🛠️ Estructura del Proyecto
El proyecto está dividido en dos capas principales:
* `/frontend`: Contiene las vistas estáticas (HTML), estilos (CSS) y la lógica de interacción del cliente (JS).
* `/backend`: Contiene el servidor en Node.js, las rutas de Express y el sistema de almacenamiento de datos.

## 🚀 Flujo de Trabajo (Fase 1 - Frontend Estático)
Para esta primera etapa, nos dividiremos las tareas en las siguientes interfaces:
1. **`index.html`** -> Encargado: [Nombre] (Diseñar landing y barra de búsqueda).
2. **`resultados.html`** -> Encargado: [Nombre] (Diseñar grilla de tarjetas).
3. **`perfil-instituciones.html`** -> Encargado: [Nombre] (Diseñar plantilla de perfil dinámico).
4. **`login.html`** -> Encargado: [Nombre] (Formularios de ingreso y registro).
5. **`panel-control.html`** -> Encargado: [Nombre] (Panel privado para la institución).
